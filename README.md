# Atlas

Atlas is an AI Agent that I am building completely from scratch to understand how production-grade AI systems work internally.

The goal is not just to build an AI assistant, but to engineer a secure, scalable and observable autonomous system similar to those used in industry.

---

## Vision

- Secure Python code execution using Docker
- DAG (Directed Acyclic Graph) task execution
- Gmail integration
- Google Calendar integration
- Evaluation (Evals) framework
- Production observability and tracing
- Memory and retrieval
- Security hardening
- Parallel tool execution
- Sandboxed execution environment

---

## Current Features

- Planner

- Docker-based Python Execution Engine (Work in Progress)
